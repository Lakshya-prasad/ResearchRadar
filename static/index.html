College Project

ResearchRadar Assistant

Designed and developed to streamline research comprehension, literature exploration, and business viability evaluation for students, scholars, and founders.

👨‍💻 Developer Profile

  • Project DeveloperLakshya Prasad
  • DepartmentComputer Science & Eng.
  • Project TitleResearchRadar
  • Project TypeFull Stack Web Application

🛠️ Technology Stack

  • BackendPython & Flask
  • DatabaseSQLite
  • FrontendHTML / CSS / JS
  • External APIsArXiv API & Groq LLM API

🌟 Project Highlights & Features

  • Single-Page Architecture: Built using clean, non-complex RESTful endpoints and modular vanilla JS.
  • PDF Parsing & Summarization: Automated text extraction and structured synthesis (Summary, Key Points, Terms).
  • ArXiv Literature Search: Real-time XML parsing for query-based scientific paper retrieval.
  • Startup Viability Scoring: Multi-dimensional scoring for innovation, market feasibility, and execution.
  • Viva & Demo Ready: Clean, well-structured codebase for easy explanation during college evaluation.
